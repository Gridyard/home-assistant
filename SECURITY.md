# Security policy

## Reporting a vulnerability

Do not report vulnerabilities in public issues. Send an email to **[security contact, added before the first
release]** with:

- the affected version of the integration, of the library `gridyard` or of the device firmware
- what an attacker can do and under which conditions, for example from inside the home network
- steps to reproduce

Leave out setup codes, meter keys, Wi-Fi passwords and readings of your own meter; synthetic values are enough.

## Supported versions

Security fixes go into the latest release.
